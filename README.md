This project formalizes an upper bound on the factor-revealing program in Definition~\ref{def:frp} in Paper/approximation-guarantee.tex for the choice gamma = 1.224 over all n >= 1.

See Formalization195.originalPrimalUpperBound_153_div_125_exact for an upper bound of 2 - (153/125 - 1)^2 (that is, approximately 1.9498) and Formalization195.originalPrimalUpperBound_195 for an upper bound of 39/20 (that is, 1.95).
